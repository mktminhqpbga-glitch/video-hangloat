# video-hangloat

Repo này chứa:

1. **Bản viết lại Muse AI Studio chạy trên MacBook** — xem thư mục
   `muse-ai-studio-mac/` (chạy bằng `python3 app.py`, không cần file
   .exe Windows). Đây là bản viết mới từ đầu, không copy mã nguồn hay
   khóa cấp phép của bản Windows gốc. Có sẵn `Dockerfile` ở gốc repo
   để chạy trên Render (xem mục Chạy trên Render trong
   `muse-ai-studio-mac/README.md`).
2. **Bản Windows gốc** `Muse AI Studio.zip` (1.0.0) — dự kiến đăng ở
   mục Releases của repo này để tải về (file 121 MB vượt giới hạn
   100 MB của file trong cây repo nên không đẩy thẳng vào repo được).

Xem hướng dẫn chi tiết trong `muse-ai-studio-mac/README.md`.
